# Группировка фактов в карточки

Этот промт описывает правила группировки. В MVP группировка выполняется
детерминированно по `card_topic`, поэтому промт используется как спецификация
и как контекст для агентного режима.

## Правила

- Один `card_topic` — одна карточка, если тема действительно целостная.
- Крупные темы (справочник, документ, поток, авторизация, ошибки, объём работ)
  получают отдельные карточки.
- Нельзя делать одну карточку на весь документ.
- Дубликаты объединяются, все `source_refs` сохраняются.
- Противоречия между источниками выносятся в `reports/conflicts.md`, карточка
  получает `review_status: needs_review`.
- Если группировка неоднозначна — `review_status: needs_review` и
  `review_note` с причиной.
- Карточки проекта ссылаются на umbrella через `parent`.

## Схема решения

```json
{
  "cards": [
    {
      "topic": "nomenklatura",
      "title": "Передача справочника «Номенклатура»",
      "fact_ids": ["doc-001:c-001:f-01"],
      "review_status": "ok",
      "review_note": null
    }
  ],
  "conflicts": []
}
```
