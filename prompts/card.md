# Рендеринг карточки

Промт описывает требования к карточке; в MVP тело карточки собирается
детерминированно из валидированных фактов, чтобы исключить выдуманные
утверждения и обеспечить воспроизводимость.

## Требования

- YAML front matter с обязательными полями.
- `id = <client>-<project>-<topic-slug>`.
- H1 — заголовок карточки, H2 — обязательные разделы профиля.
- Не добавлять H4 без необходимости.
- Каждый раздел содержательный или явно помечен `Нет данных в источниках.`
- В `## Источники` — файлы, разделы и `block_id`.
- В `## Открытые вопросы` — только конкретные вопросы.
- В `## Ограничения и допущения` — явные допущения.
- В `## Связанные заметки` — wiki-ссылки на umbrella и связанные карточки.

## Схема входных данных

```json
{
  "topic": "nomenklatura",
  "title": "Передача справочника «Номенклатура»",
  "profile": "integration",
  "facts": [],
  "project": {"client": "marta", "project": "toplog-rc"}
}
```
